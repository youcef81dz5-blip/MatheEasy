# 📄 DocExtract — Space Demo

حوّل مستنداتك العلمية (PDF ممسوح ضوئياً، صور، DOCX...) إلى **Markdown + معادلات LaTeX** قابل للنسخ والتحرير، مع تصحيح ذكي عبر Gemini.

- يعمل فوراً بوضع **Flash** (بدون أي مفاتيح) حتى 10MB / 20 صفحة
- لأداء أعلى: أضف `MINERU_TOKEN` في Settings → Variables and secrets
- لتصحيح المعادلات بالذكاء الاصطناعي: أضف `GEMINI_API_KEY`

الكود المصدري: [MatheEasy على GitHub](https://github.com/youcef81dz5-blip/MatheEasy)
